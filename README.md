# 斜面調査記録アプリ

完全オフラインで動く、箇所ごとの写真＋構造化データ記録アプリです。

## ファイル

- `index.html` … アプリ本体
- `manifest.json` / `service-worker.js` / `icon-192.png` / `icon-512.png` … ホーム画面追加＆オフライン動作用

## 公開方法（現場アプリと同じ手順）

1. この5ファイルをまとめて、GitHubの新しいリポジトリ（例：`slope-survey`）にアップロード
2. Settings → Pages で公開（例：`bluenilegear.github.io/slope-survey/`）
3. iPhone・iPad それぞれの Safari でそのURLを開き、「ホーム画面に追加」

## 使い方の流れ

1. 起動したら、まず**端末の役割**を選ぶ（写真あり／データ入力のみ）
2. **現場**を新規作成 or 選択
3. **箇所**を追加すると、箇所番号が自動採番される
4. 箇所の中で、写真撮影・斜面基礎情報・ボイスメモ・調査対象（地質／地形／堆積物／水浸食／落石源／人工構造物／ほか）を記録
5. 現場全体の一覧画面で「書き出し」→ その日のデータをJSONとして共有／保存

## 運用メモ（相談してきた内容の反映）

- **役割分担**：Wakaさんが撮影・観察・指示、相棒さんがiPadでデータ入力。箇所番号は声で共有し、iPad側は手入力（自動採番に頼らない）
- **写真の保存**：撮影後に出る共有シートで「画像を保存」を選ぶとカメラロールに保存されます（Files保存だとケーブル転送で見えません）
- **宿でのデータ集約**：iPad→iPhoneへAirDropでJSONを送り、iPhoneのUSB-C端子にUSBメモリを挿して保存 → Windows PCへ
- **岩級の自動判定**：軟硬区分・形状区分・割れ目状態区分の3つを選ぶと自動計算されます。表は資料から転記したものなので、現場に出る前に元資料と一度突き合わせてください
- **ボイスメモ**：録音のみ（自動文字起こしはなし）。自由記入欄はiPhone標準の音声入力（キーボードのマイクボタン）が使えるか、事前に機内モードで試しておくのがおすすめです
